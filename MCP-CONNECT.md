# Подключение MCP-сервера whisper-studio

## Что это

Локальный MCP-сервер (stdio) приложения Whisper Studio. Он даёт ИИ-агенту те же записи, что видит
пользователь в приложении, включая его правки: распознать файл, найти расшифровку, вычитать её,
поправить спикеров, пополнить словарь.

- **Модели.** Ансамбль из 7 моделей распознавания (Whisper large-v3, ru-large-v3, de-turbo,
  Qwen3-ASR, GigaAM v3, Canary v2, T-one); немецкие термины, записанные кириллицей,
  восстанавливаются по звучанию.
- **Таймкоды** пословные (wav2vec2), **спикеры** размечены.
- **Офлайн.** Всё работает без сети и без токенов.

Сам MCP-сервер модели не загружает: задачи встают в общую очередь, считает их фоновый воркер
(см. README, «Фоновый воркер и очередь»).

## Что нужно

| Что | Пример |
|---|---|
| Python из venv приложения | `<путь к venv>\Scripts\python.exe` |
| Корень репозитория (пакет `whisper_studio`) | `<путь к репозиторию>` |
| Папка данных (необязательно, иначе `%LOCALAPPDATA%\WhisperStudio`) | `<папка данных>` |

Команда запуска: `python -m whisper_studio mcp`. Переменные окружения:

- `PYTHONPATH=<путь к репозиторию>` — обязательно;
- `PYTHONIOENCODING=utf-8` — обязательно на Windows;
- `WHISPER_STUDIO_HOME=<папка данных>` — если папка данных не по умолчанию; должна совпадать с той,
  что у приложения, иначе агент увидит другую библиотеку.

Проверка вручную (сервер ждёт JSON-RPC на stdin; Ctrl+C — выход):

```bat
set PYTHONPATH=<путь к репозиторию>
set PYTHONIOENCODING=utf-8
<путь к venv>\Scripts\python.exe -m whisper_studio mcp
```

## Claude Code

```bat
claude mcp add whisper-studio --scope user ^
  -e PYTHONPATH=<путь к репозиторию> -e PYTHONIOENCODING=utf-8 -e WHISPER_STUDIO_HOME=<папка данных> ^
  -- <путь к venv>\Scripts\python.exe -m whisper_studio mcp
```

`--scope user` — сервер доступен во всех проектах; `--scope project` — только в текущем
(запись в `.mcp.json`). Проверка: `claude mcp list`.

## Codex

В `%USERPROFILE%\.codex\config.toml`:

```toml
[mcp_servers.whisper-studio]
command = '<путь к venv>\Scripts\python.exe'
args = ["-m", "whisper_studio", "mcp"]
startup_timeout_sec = 30
tool_timeout_sec = 3600

[mcp_servers.whisper-studio.env]
PYTHONPATH = '<путь к репозиторию>'
PYTHONIOENCODING = "utf-8"
WHISPER_STUDIO_HOME = '<папка данных>'
```

## Claude Desktop и любой другой клиент

Блок для `mcpServers` (в JSON обратные слэши удваиваются):

```json
"whisper-studio": {
  "type": "stdio",
  "command": "<путь к venv>\\Scripts\\python.exe",
  "args": ["-m", "whisper_studio", "mcp"],
  "env": {
    "PYTHONPATH": "<путь к репозиторию>",
    "PYTHONIOENCODING": "utf-8",
    "WHISPER_STUDIO_HOME": "<папка данных>"
  }
}
```

Добавляйте блок к существующим серверам, а не вместо них. Перед правкой конфига сделайте копию.
После правки перезапустите клиент.

## Как агенту работать

1. **Сначала искать готовое.** `transcribe_audio(path)` сам находит прежнюю расшифровку этого файла
   (в том числе исправленную руками) и возвращает её; новую делает только `force=true`. По имени
   файла ищет `find_transcripts`, по тексту — `search_transcripts`.
2. **Распознавание.** `transcribe_audio(path)` — один файл с ожиданием; `start_transcription([paths])`
   — пачка, затем `get_status` (без id — вся очередь).
   - Не задавать `language`, `model`, `profile`, `num_speakers` без просьбы пользователя: тогда
     берутся умолчания приложения.
   - Имена и термины этой записи передавать в `glossary`. Словарь проекта подставляется сам.
3. **Вычитка.** `proofread_pack(id)` возвращает инструкции, словарь, контекст проекта и расшифровку.
   - Сомнительные слова помечены ⟨…⟩; под репликой — что услышали другие модели, только отличия:
     `«двадцать пятый»→«двадцать четвёртое» (GigaAM, Qwen3)`.
   - Длинная запись приходит страницами: в конце сказано, с какого `from_segment` продолжить.
   - Исправлять только ошибки распознавания: немецкое кириллицей → по-немецки, имена по словарю,
     ослышки, повторы-галлюцинации. Выбирать из вариантов. Не перефразировать и не переводить.
   - Вернуть правки: `apply_corrections(id, {"g12": "полный исправленный текст"})`, только изменённые
     реплики. Это один шаг отмены в приложении; правки ИИ помечены ✦.
4. **Спикеры.** Если их больше, чем реально говорит: `rediarize(id, num_speakers=2)`. Пересчёт
   мгновенный, голоса закэшированы.
5. **Словарь.** Новые имена и термины —
   `update_dictionary(add_terms=[...], add_replacements={"как распознано": "как правильно"})`.
6. **⚠** — возможная галлюцинация на тишине или музыке; не выдавать за факт. «неразборчиво» —
   модели услышали разное: это речь, но сверить с вариантами.
7. **Эталон.** Записи с пометкой «эталон» выверены на слух; их текст не вычитывать и не править —
   инструменты откажут.

## Инструменты

`transcribe_audio`, `start_transcription`, `get_status`, `list_transcripts`, `find_transcripts`,
`search_transcripts`, `get_transcript` (`format`: `segments`, `txt`, `md`, `srt`, `vtt`, `json`;
страницы: `from_segment`, `start_time`, `end_time`, `max_chars`; `mark_uncertain`), `proofread_pack`,
`apply_corrections`, `rediarize`, `edit_segment`, `replace_text`, `rename_speaker`,
`set_segment_speaker`, `undo`, `get_dictionary`, `update_dictionary`, `export_transcript`,
`list_models`.

Id расшифровки — целиком или последние 6 символов. Ответы — компактный текст, ошибки приходят с
`isError` и объяснением по-русски. Правки через MCP открытое приложение подхватывает само.

## Особенности и ограничения

- **Лёгкий сервер.** Свой JSON-RPC на стандартной библиотеке, без MCP SDK: отвечает на `initialize`
  за доли секунды. Версии протокола: 2024-11-05, 2025-03-26, 2025-06-18, 2025-11-25.
- **stdout занят протоколом.** Сервер пишет в stdout только MCP, логи — в stderr.
- **Распознавание небыстрое.** Ансамбль на RTX 2060: 11 минут звука — около 13 минут. Первый запуск
  воркера после простоя — ещё несколько секунд на импорт и загрузку моделей.
- **Таймаут клиента.** Если у клиента короткий таймаут вызова, использовать `start_transcription` +
  `get_status` вместо `transcribe_audio`.
- **Одна видеокарта на всех.** Задачи MCP, приложения и CLI идут в общую очередь, один воркер на
  машину. Он стартует по требованию, даже если приложение закрыто, и выходит через 2 минуты простоя.
  Не запускайте рядом другой процесс на той же видеокарте: не хватит видеопамяти.
