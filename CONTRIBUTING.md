# Как помочь проекту

Спасибо, что заглянули! Баг-репорты, идеи и пулл-реквесты — всё пригодится.

## Сообщить об ошибке

Откройте issue по шаблону «Ошибка» и укажите:

- **ОС** — версия Windows (10/11, сборка);
- **видеокарту** и версию драйвера (`nvidia-smi` покажет обе), объём видеопамяти;
- **версию Python** и, если знаете, коммит или версию приложения;
- **команду или действие**, после которого всё сломалось (`ws transcribe ...`, кнопка в окне и т. п.);
- **лог** — `HOME\queue\worker.log`, где `HOME` — папка данных (по умолчанию
  `%LOCALAPPDATA%\WhisperStudio`, или та, что задана в `WHISPER_STUDIO_HOME`). Хватит последних
  50–100 строк вокруг ошибки.

> ⚠️ **Перед отправкой уберите из логов и расшифровок личные данные**: имена, телефоны, адреса,
> номера, пути к файлам с вашим именем пользователя, куски текста записей.
> Issue на GitHub видят все.

## Запуск тестов

```
python -m unittest discover -s tests
```

- Тесты сами создают временную папку и подставляют её в `WHISPER_STUDIO_HOME`, так что ваши
  настоящие записи и библиотеку они не трогают.
- Тесты, которым нужны настоящие модели, ищут их в `WS_REAL_HOME` (по умолчанию —
  `%LOCALAPPDATA%\WhisperStudio`). Если моделей нет, такие тесты пропускаются.
- Перед пулл-реквестом прогоните хотя бы тесты того модуля, который меняли.

## Стиль кода

- **Комментарии и docstring в коде — по-английски**, документация в `docs/` и README — по-русски.
- **Лёгкие модули остаются лёгкими**: CLI, сервер, MCP-сервер и хранилище не импортируют
  `torch` и другие тяжёлые библиотеки на верхнем уровне — только внутри функций, где они нужны.
- Небольшие пулл-реквесты с одной идеей проще проверить. Если меняется поведение — добавьте тест.

## Правило приватности для примеров

**Никогда не используйте настоящие записи, расшифровки и настоящие имена** — ни в issue, ни в
тестах, ни в документации, ни в примерах. Для тестов годятся синтетический звук (например, TTS) и
выдуманные имена, адреса и номера. Если для
воспроизведения ошибки нужна запись — опишите её (длина, язык, сколько говорящих, качество), а
не прикладывайте.

Отправляя пулл-реквест, вы соглашаетесь, что ваш вклад распространяется под лицензией проекта
(GPLv3).
