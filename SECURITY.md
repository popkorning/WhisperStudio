# Безопасность

*WhisperStudio runs entirely on your computer. To report a vulnerability, please use GitHub
private vulnerability reporting (Security → Report a vulnerability); do not open a public issue.*

## Модель угроз

Приложение работает только локально: записи, расшифровки и модели лежат на вашем диске, в сеть
ничего не отправляется (кроме скачивания моделей, когда вы сами их ставите). Локальный
HTTP-сервер слушает только `127.0.0.1`.

## Как сообщить об уязвимости

Пожалуйста, **не открывайте публичный issue**. Вместо этого:

1. На странице репозитория откройте **Security → Report a vulnerability** (приватный advisory).
2. Опишите проблему, шаги воспроизведения и что, по-вашему, может сделать атакующий.
3. Не прикладывайте настоящие записи и расшифровки — только синтетические примеры.

Отвечаем по мере сил; исправление и описание публикуем после того, как оно готово.

## Что входит в рамки

- **Локальный HTTP-сервер** (`whisper_studio/server.py`): доступ к API с других сайтов, открытых в
  браузере (CSRF, DNS rebinding, обход проверки `Host`/origin), доступ с других машин.
- **MCP-сервер** (`whisper_studio/mcp_server.py`): выход инструментов за пределы своей папки
  данных, выполнение команд, утечка содержимого записей.
- **Работа с файлами**: обход путей (path traversal), разбор аудио и видео,
  импорт и экспорт расшифровок, распаковка моделей.

## Что не входит

- Уязвимости в сторонних библиотеках и моделях (torch, transformers, ffmpeg и т. п.) — о них лучше
  сообщать их авторам; но если мы используем их небезопасно, это к нам.
- Атаки, для которых у злоумышленника уже есть доступ к вашей учётной записи Windows.
- Ошибки распознавания речи и текста.
