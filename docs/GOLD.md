# Эталон: как выверить запись на слух

Эталон — текст, проверенный человеком на слух. По нему приложение (`whisper_studio/gold.py`)
считает, сколько ошибается каждая модель, подбирает веса ансамбля и проверяет новые идеи. Без
эталона любое «улучшение» — догадка (см. [DECISIONS.md](DECISIONS.md), п. 0).

## Что делать

1. Отметить запись как эталон (меню «…» → «Сделать эталоном») или собрать эталонную запись из
   кусков разных записей.
2. Слушать реплику и, если текст ровно тот, что сказан, отметить её «Проверено» (Enter).
   Если нет — исправить (E): исправленная реплика считается проверенной сама. Разделение и
   склейка реплик тоже отмечают результат проверенным. Удалить реплику — значит «здесь ничего
   не сказано», это тоже проверка.
3. Проверять можно частями и в любом порядке: в оценку идут только проверенные места.
   Непроверенные реплики просто не участвуют.

В режиме проверки варианты моделей по умолчанию скрыты: догадки моделей подсказывают слушателю,
что слышать.

## Правила

- **Писать, что сказано, а не как правильно.** Повторы («я, я думаю») — как сказаны.
  Оговорки не исправлять. Междометия «э», «м-м» — не писать.
- **Слово, которого не было**, — удалить. **Пропущенное слово** — дописать в ближайшую реплику.
- **Немецкие слова — латиницей**, как пишутся по-немецки (Wohnung, Rathaus).
  Русское окончание можно оставить кириллицей («Wohnungу»): при оценке оно отбрасывается.
  Имена и названия — как в словаре проекта.
- **Числа — в любом виде:** «двадцать пять» или «25» считаются одинаково.
  Знаки препинания и заглавные буквы не важны.
- **Не разобрать на слух** — не угадывать: заменить это место на `???` (Ctrl+/). Такой кусок
  пропускается при оценке.
- **ИИ-вычитка на эталоне отключена** — и в приложении, и через агента (MCP): инструменты откажут.
  Правки только свои, на слух, иначе эталон перестанет быть эталоном.
- Спикеров проверять не нужно.

## Что идёт в оценку

Ансамбль режет запись на куски до 25 с, оценка идёт по кускам. Кусок считается, только если
все слова в нём из проверенных реплик, его не задевает ни одна непроверенная реплика и в нём
что-то проверяли (есть проверенная реплика или удалённая как «ничего не сказано»). Кусок с `???`
пропускается. Поэтому одна непроверенная реплика выключает кусок вокруг себя целиком.

## Сколько

Хватает 25–35 минут проверенного аудио из нескольких разных записей (шум, разные собеседники,
немецкая речь). Разница меньше ~1,5% WER на таком объёме — шум; на 6 минутах — тем более.

## Оценка

Оценка повторяет конвейер: слияние, глоссарий и термины по звучанию, затем замены из словаря.
Считается по сохранённым гипотезам, без GPU.

В приложении: раздел «Эталон» (Ctrl+3) → «Оценить» (с подбором весов — дольше). Считается в
отдельном процессе на CPU, очередь распознавания не ждёт. Итог — `HOME\gold\latest.json`, история —
`HOME\gold\history.jsonl`.

Из командной строки:

```bat
ws gold-eval --tune                              :: по всем эталонам
python tools\asr_eval.py --ref <id> --tune       :: по одной записи
```

`--ref` эталонной записи берёт только проверенные куски; `--ref` обычной записи считает её
проверенной целиком, `<id>:120-420` — только эти секунды. `--json` — результат в том же виде,
что `latest.json`. Веса в `ensemble.MEMBERS` стоит менять, только если улучшение держится и на
записи, которая не участвовала в подборе.
